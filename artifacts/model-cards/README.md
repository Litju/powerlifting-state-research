# Model Cards

## Scope

Model-card exports linked to typed model definitions.

## Publication rule

A card describes model identity, intended synthetic task, training provenance, evaluation evidence, limitations, and per-checkpoint rights.

## Current cards

- [Public-Native Temporal Capacity-Change Model](public-native-temporal-capacity-change.md) — historical Sobol evidence and separately identified PUBLIC_NATIVE IID fitted evidence.
- [Historical Model Evidence Lineage](historical-model-evidence-lineage.md) — supported historical families and explicit missing evidence.
- [PUBLIC_NATIVE IID Comparator Suite](public-native-comparator-suite.md) — six new comparator profiles, per-target results, complexity, compute, validation isolation, and claim boundaries.

Cards may record approved historical identity and hash metadata. They do not redistribute private source, data, weights, checkpoints, or archives. Unknown rights or untraceable inputs block publication of an artifact.
