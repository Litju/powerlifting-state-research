# Models

## Scope

Model family, training, comparator, checkpoint, and publication policy.

## Model artifact rules

Typed Python owns model-family metadata. Do not infer model identity from a checkpoint filename or import private model definitions.

The repository contains public-safe checkpoint metadata for the three-seed PUBLIC_NATIVE temporal expert; its verified checkpoint bytes are not tracked and are deferred to M7/M8 release packaging. Historical checkpoint bytes remain private. Model artifacts need a model card and explicit rights/provenance metadata.
