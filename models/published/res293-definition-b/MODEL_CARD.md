# RES-293 Definition B fitted states

This release contains the 30 original final-epoch fitted states from the frozen RES-293 Definition B study: six configurations (`C1`-`C6`) crossed with five initialization seeds (`293201`-`293205`). The state file names, byte lengths, SHA-256 values, final-state digests, and fit details come from the exact original [seal manifest](source-evidence/seal-manifest.json), copied from result-bearing commit `207e5c1fa3abd5271e2f0e94a46fc12fe1406636` without changes. The original [frozen worker source](source-evidence/res293_fit_worker.py), protocol, and protocol-freeze receipt are included as source evidence. Their hashes are recorded in the [artifact manifest](artifact-manifest.json).

`C1` and `C2` are 2,625-parameter linear learners. `C3`-`C6` are 28,099-parameter compact nonlinear learners. Their representations are summary (`S`), ordered (`O`), context-only summary, and summary with assessment/load omitted, as specified in the frozen protocol. The seed is the initialization identity; no new fitted-instance IDs are inferred or substituted.

Each `.state.npz` was loaded with `allow_pickle=False`. Tensor names, float32 dtypes, shapes, finiteness, parameter count, and the recorded final-state digest matched the frozen worker. Replaying every saved development and validation prediction with the original RES-293 feature preparation, normalization, and worker produced byte-identical output for all 60 prediction files. No fit was repeated, and no result file was changed.

The original execution receipt records that state distribution was withheld at run time. The owner authorization recorded in [the release rights note](../../../provenance/model-artifact-redistribution.md) applies to these later published copies only; it does not change the study protocol or results. The states are MIT project artifacts trained on the project-generated synthetic IID realization. The underlying dataset remains CC-BY-4.0 and requires attribution. This evidence supports synthetic-study reproducibility only, not real-athlete validity.

After a clean clone, run `uv run python scripts/verify_published_model_artifacts.py` to verify all 30 byte hashes and load each state strictly into its frozen model structure.
