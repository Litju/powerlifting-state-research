# Latent Capacity-Change Forecasting with Transient Performance Expression: realization manifests

## Scope

Public realization manifest/checksum home. Generated JSONL stays under `data/synthetic/` and is not checked into Git.

## Manifest contents

The checked-in `iid-production.json` records the `DatasetRealizationManifest` for the public-native IID run, including its DatasetSpec identity, generator, RNG seeds, schema, split IDs, coverage, entity/row counts, file checksums, origin, and redistribution terms. Regenerate with `python -m powerlifting_state_research.benchmarks.latent_capacity_change_with_transient_expression_forecasting` from the repository root. Run `uv run --locked python scripts/verify_public_iid_production.py --check` to regenerate into a fresh directory and verify the checked-in manifest.

The historical projection, public-native IID BenchmarkSpec, and each realization have separate identities. The IID DatasetSpec differs from the historical scrambled-Sobol DatasetSpec. Generated bytes are public synthetic data and are not a historical dataset copy.
