# Latent Capacity-Change Forecasting with Transient Performance Expression: realization manifests

## Scope

Public realization manifest/checksum home. Generated JSONL stays under `data/synthetic/` and is not checked into Git.

## Manifest contents

The checked-in `public-v4.json` records the `DatasetRealizationManifest` for the default public run, including its dataset-spec identity, generator, RNG seeds, schema, split IDs, coverage, entity/row counts, file checksums, origin, and redistribution terms. Regenerate with `python -m powerlifting_state_research.benchmarks.latent_capacity_change_with_transient_expression_forecasting` from the repository root.

The benchmark declaration and each realization have separate identities. The generated bytes are public synthetic data and are not a historical dataset copy.
