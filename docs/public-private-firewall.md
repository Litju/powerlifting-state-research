# Public/private firewall

This repository contains newly authored public material and public-safe projections of scientific specifications. Its MIT and CC BY 4.0 notices apply only to the file scopes they name.

Do not add private historical source code, datasets, model weights, checkpoints, archives, old Git objects, credentials, private absolute paths, internal workspace instructions, or unresolved third-party material. Historical names and component IDs may appear only as provenance or alias metadata; they do not authorize copying the source artifact.

Every tracked file has an origin and license row in provenance/PUBLIC_FILE_ORIGINS.csv. Every future data, model, result, or figure artifact needs a source record, redistribution status, access conditions, and rights decision before publication.
