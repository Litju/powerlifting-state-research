## Artifact access and rights

Public software is MIT; project-authored Markdown is CC BY 4.0. The generated public dataset requires CC BY 4.0 attribution. Individual manifests govern model/data/result artifacts. Every tracked file has an origin/license row in the public ledger.

The owner-authorized integration contains newly authored methods, aggregate findings, negative results and access limitations. It does not copy private reports/dossiers, manuscripts, workspace conversations, raw cohorts, latent test truth, predictions, row scores, fitted uncertainty parameters or private scoring adapters. Hashes establish identity, not access or redistribution permission.

The [named model authorization](../provenance/model-artifact-redistribution.md) permits specific public-native checkpoints, fitted states and listed metadata. It excludes historical private checkpoints and source archives and does not extend automatically to later uncertainty models. The [rights clarification](../provenance/normalization-and-rights-clarification.md) records the original normalizer discrepancy and conflicting private dataset-MIT shorthand; original dataset attribution remains applicable.

Do not add credentials, private absolute paths, internal execution instructions, unresolved third-party bytes or unrelated binaries. Retain original aliases and identifiers where necessary for evidence genealogy, while using descriptive scientific navigation. New artifacts need their own identity, origin, rights and access decision.

[Level A inspection and Level B numerical reproduction](reproducibility.md#public-and-restricted-reproduction) are separate. Restricted evidence requires artifact-specific rights and controlled access before transfer. No blanket public release of private artifacts is established by this documentation summary.
