# Results and public artifacts

Predictions, evaluation results, summary tables, figure inputs, figures, audit outputs, study outputs, checksums, and release bundles occupy separate homes. Generated artifacts bind to the source benchmark, realization, model, evaluation, and run identities needed to interpret them.

Commit small source tables and manifests when they support review. Treat large data, weights, generated predictions, and bundles according to the rights and storage policy. Figures should include accessible source alternatives. The initial repository contains no historical result bytes or trained checkpoints.
