# Model families and reference comparators

Model-family and training declarations belong in the Python package. Reference implementations should be small, reproducible comparators with a clearly stated input boundary, objective, tuning procedure, and supported claim.

The bootstrap contains no model implementation, trained weight, or checkpoint. Future checkpoint manifests must identify the model, source and training-data identities, license, redistribution status, and access conditions. Weight files are excluded unless their rights are explicitly cleared.
