# Scientific naming decisions

This audit applies the semantics frozen in RES-266/267/268, the technical characterizations in RES-382, and the recovered specimen/component mappings. Names are descriptive metadata; existing versioned component IDs remain bound identity references.

## Terminology decisions

The five-output and four-output target sets include target-load velocity and load at a reference velocity. The names use load–velocity wording for those paired outputs only; they do not claim a validated individual load–velocity profile or estimate of maximal strength. The next-set output is explicitly a velocity-loss target, so the established term is retained for that output. [LeMense et al., 2024, load–velocity relationship review](https://pubmed.ncbi.nlm.nih.gov/38416447/) and [Pareja-Blanco et al., 2017, velocity loss during resistance training](https://pubmed.ncbi.nlm.nih.gov/27038416/).

Fitness–fatigue terminology was rejected. The recovered system distinguishes chronic capacity from transient performance expression/suppression. It does not define separate fitness and fatigue responses to training impulses or an antagonistic impulse-response law. The classical system explicitly models performance as the difference between fitness and fatigue functions. [Calvert, Banister, Savage, and Bach, 1976](https://ieeexplore.ieee.org/document/5409179/).
