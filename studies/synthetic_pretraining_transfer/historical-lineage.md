# Surviving historical G4 evidence

G4 survives as the study name “Synthetic-pretraining transfer; retrospective
study,” with aliases G4 / ALI-544 and pl_study_g4_synthetic_pretraining. The
study registry classifies it as research, not as a benchmark version. The
historical-source record attaches G0–G4 to the latent-capacity benchmark
specimen. These facts establish identity and provenance metadata only.

The historical study and result homes at RES-292's starting main contain only
bootstrap README files. No rights-cleared original G4 protocol, methodology,
participant rows, synthetic generator, fitted model, prediction, score,
uncertainty estimate, scientific report, or negative-result register was
recovered. No experiment, model, score, or negative finding is attributed to
historical G4 here. The old result-home “PROVEN” marker records bootstrap
classification and is not evidence of a scientific result.
