# Provenance

## Scope

Public file-origin and historical-source provenance policy.

The origin ledger covers every tracked file. Historical benchmark aliases and source component identities are centralized as metadata in the typed provenance modules; they are not canonical public names. Superseded dataset realization identities remain documented as provenance and do not grant rights in prior artifacts.

Do not include source archives, data/model bytes, absolute workspace paths, credentials, old Git metadata, or unresolved rights. A provenance reference never grants a license to the referenced historical artifact.
