# Interchange schemas

The JSON Schema files describe public interchange records for benchmark specifications, dataset realizations, predictions, evaluation results, and artifact rights. They are generated by scripts/export_benchmark_registry.py from typed Python declarations and schema-only typed records in that script.

The exported JSON files are not a second hand-edited semantic authority. They describe record structure only; semantic and cross-field invariants are enforced by the Python contract validator and are not all expressible in these schemas. The schemas do not implement generation, prediction, evaluation, or artifact identity engines.
