# Stable-Slope/Tilt Four-Target Athlete-State Forecasting

Characterize four performance targets under a stable-slope/tilt synthetic athlete-state model.

**Research question:** Within a stable-slope/tilt synthetic athlete-state world, how accurately can models forecast target-load velocity, reference-velocity load, next-set velocity loss, and competition-day capacity from point-in-time histories at four origins, including day 340–365? This does not establish causal training effects, real-athlete accuracy, or state/parameter recovery.
