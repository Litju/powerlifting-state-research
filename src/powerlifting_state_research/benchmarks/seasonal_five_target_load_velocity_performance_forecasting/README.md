# Seasonal Five-Target Load–Velocity and Performance Forecasting

Characterize five source-defined outputs in an early synthetic seasonal system, including load-velocity observations, within-session velocity loss, and competition-day capacity.

**Research question:** From completed records at each query time, how well can a model forecast target-load bar velocity, load at a reference velocity, session shift, next-set velocity loss, and competition-day capacity? This describes the synthetic task and does not establish real-athlete validity or latent-state identification.
