# Observed-Origin-Referenced Capacity-Change Forecasting

Forecast future modeled capacity relative to a noisy observed-origin assessment in a synthetic dose-history world.

**Research question:** At the forecast origin, can a model using noisy performance observations through that origin and the participant-visible declared dose/intensity plan predict future modeled capacity relative to the noisy observed-origin assessment for squat, bench, and deadlift at horizons 14, 28, and 56 days? This is not a difference between two observed performance assessments, a causal effect, or the same estimand as latent-origin capacity change.
