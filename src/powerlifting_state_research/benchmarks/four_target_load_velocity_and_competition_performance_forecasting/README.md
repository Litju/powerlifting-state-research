# Four-Target Load–Velocity and Competition Performance Forecasting

Characterize four powerlifting performance targets in a longitudinal synthetic system.

**Research question:** From point-in-time completed histories, how accurately can models forecast target-load velocity, load at a reference velocity, next-set velocity loss, and competition-day capacity over 25 days? This does not establish causal training effects, real-athlete accuracy, or state/parameter recovery.
