# Observed-Origin Performance-Change Forecasting

Characterize a plan-conditional observed-origin performance-change estimand in a synthetic dose-history world.

**Research question:** At the forecast origin, can a model using noisy performance observations through that origin and the participant-visible declared dose/intensity plan predict future modeled capacity minus the noisy observed-origin assessment for squat, bench, and deadlift at horizons 14, 28, and 56 days? The observed-origin target is not pure latent capacity change, a causal effect, or directly comparable with a latent-origin target.
