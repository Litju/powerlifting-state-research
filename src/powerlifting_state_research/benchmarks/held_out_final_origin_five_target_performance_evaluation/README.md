# Held-Out Final-Origin Evaluation of Five Performance Targets

Evaluate five performance targets on an independent held-out final origin within the class-normalized synthetic system.

**Research question:** Using the refined class-normalized synthetic cross-lift system, can predictors trained on four earlier 25-day origins predict the same five outputs for an independent final-origin draw at days 340–365? This evaluates transfer within synthetic support, not human or general-domain transfer.
